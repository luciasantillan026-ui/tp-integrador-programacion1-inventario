### Descripción del proyecto

El presente proyecto consiste en el desarrollo de un Sistema de Control de Inventario para una ferretería, utilizando el lenguaje de programación Python.

El programa permite administrar las herramientas disponibles, consultar cantidades, identificar productos agotados, agregar nuevos productos y actualizar el stock mediante movimientos de venta e ingreso de mercadería.

El sistema cuenta con un menú interactivo que facilita el acceso a las distintas operaciones y utiliza validaciones para evitar datos incorrectos.

### Funcionalidades

1. Cargar herramientas con existencias iniciales.
2. Visualizar el inventario.
3. Consultar el stock de una herramienta.
4. Generar un reporte de herramientas agotadas.
5. Agregar nuevos productos.
6. Actualizar el stock mediante ventas o ingresos.
7. Salir del sistema.
